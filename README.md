# Astra Study

An AI-powered Multimodal Study Assistant built using:

- FastAPI
- Streamlit
- LangChain
- LangGraph
- OpenAI GPT-5
- GPT-5 Vision
- PostgreSQL
- Qdrant
- LangSmith
- Langfuse

## Features

- User Authentication
- Multiple Chat Sessions
- Multimodal Document Upload
- Semantic Chunking
- Hybrid Retrieval
- Citation Support
- Guardrails
- Conversation Memory
- OCR
- Vision-based Document Understanding
